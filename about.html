About

伝えるためのデザインを
丁寧につくります。

01  Attitude

相手の想いやサービスの魅力をきちんとくみ取り、形にすることを大切にしています。 わからないことは素直に聞き、仮説を立てて試し、改善を重ねる。 その繰り返しが、良い作品につながると考えています。

02  Design

余白・文字組み・色のバランスを大切にしています。 情報が整理されて初めて、デザインは「伝わる」ものになると考えています。 見た人が迷わず、すっと情報が伝わる画面づくりを心がけています。

03  Code

デザインしたものを、そのまま実装することを心がけています。 HTML / CSS / JavaScript を用いて、再現性の高いコーディングを行い、 デザインと実装のあいだにすき間をつくらない制作を目指しています。
